# La Buena Mesa - REST API

API RESTful desarrollada con Laravel para gestionar los elementos del menú del restaurante **La Buena Mesa**.

El proyecto permite realizar operaciones CRUD (Crear, Consultar, Actualizar y Eliminar) sobre los elementos del menú utilizando una API REST y Eloquent ORM.

## Tecnologías utilizadas

- PHP 8.2+
- Laravel 13
- Eloquent ORM
- SQLite
- Composer
- REST API
- Git y GitHub

## Requisitos

Antes de instalar el proyecto debes tener:

- PHP 8.2 o superior
- Composer
- Git
- Laravel
- Laragon, XAMPP o un servidor PHP equivalente
